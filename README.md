# 3D_CHECKERS_GAME
Welcome to the classic game of Checkers — built just for fun and learning!

This is a simple two-player checkers game that brings the traditional board game to your screen. Whether you're looking to pass time or explore how board game logic works in code, you're in the right place.

 What's Inside?

- Classic checkers gameplay
- Two-player mode on the same device
- Piece movement, jumping, and king promotion
- Clean and simple interface (with Pygame, if you're running the GUI version)

 Getting Started

To run this project, you'll need *Python 3* installed on your machine. If the game uses a graphical interface (like Pygame), you can install the required libraries by running:

```bash
pip install -r requirements.txt
```
Then start the game with:

python src.py
